## 一、目标

设计、分级和复盘山地长课时，使用多维负荷与吸收闭环：

> 计划刺激 → 完成长课 → 观察 24–48 小时 → 判断是否吸收 → 决定下一次进阶

不得只用时长、D+、公里数或平均心率给山课贴上“轻松”“高质量”或“已完成”的标签。

## 二、外部负荷

至少记录：

- 山地移动时长；
- 距离与实际可跑里程；
- D+ 与 D−；
- 最长连续爬升和最长连续下降；
- 坡度与技术地形，如台阶、泥地、碎石和陡土坡；
- 热湿、海拔、负重与补给条件。

相同 D+ 不等于相同训练成本。连续长陡坡和技术下降会提高局部峰值与离心成本；短坡反复或较可跑路线可能带来更多跑动和累计冲击。

## 三、内部反应

结合：

- 心率与强度分布；
- session RPE 与呼吸体感；
- 心率漂移和配速衰减；
- 后半程是否仍能按计划跑动；
- 哪个局部肌群最先成为限制因素；
- 补给和胃肠能否继续执行。

内部反应用于解释身体为外部工作付出的代谢代价，不得替代机械成本判断。

## 四、机械与神经肌肉成本

重点检查：

- 真实 D−、长连续下降与技术难度；
- 台阶和明显制动型地形；
- 股四、小腿、足底、跟腱、膝与脚踝的局部疲劳；
- 疲劳后的动作控制、落脚质量与稳定性；
- 是否出现疼痛、代偿、脚步拖沓或下坡失控。

低心率山课仍可能具有很高的机械和神经肌肉成本。

## 五、相对新颖度

将本次负荷与最近约 4–6 周已经稳定暴露过的负荷比较。4–6 周只是实务监控窗口，不是固定生理阈值。

分别比较：

- 总时长、D+ 与 D−；
- 最长连续爬升与下降；
- 技术地形和坡度；
- 热湿、海拔、负重与鞋履；
- 疲劳后可跑性与补给要求。

重复暴露可降低部分肌肉酸痛和损伤反应，但不得假定神经肌肉疲劳同比下降。绝对数字仍要结合近期训练史与训练后反应。

## 六、24–48 小时吸收验证

完成不等于吸收。长课后继续观察：

- 是否出现局部疼痛、晨起第一步疼或步态改变；
- DOMS、腿沉和足踝反应是否在可接受范围；
- 睡眠、食欲、主观精力和训练欲望是否恢复；
- 标准化 easy / HRex 是否回到正常范围；
- 下一堂关键力量、阈值或 ME 是否能保持质量。

如果一堂课持续破坏后续关键训练，即使当日完成良好，对当前周期仍可能过量。

## 七、进阶规则

普通建设课使用：

> 一个主变量优先推进，其余变量保持在近期熟悉区间

主变量可选：

- 时长；
- D+；
- D−；
- 最长连续坡段；
- 技术难度；
- 疲劳后可跑性；
- 补给、热湿、夜间或装备执行。

不得机械按小时线性增加，也不得为了完成数字临时补爬升或下降。

比赛专项模拟可以有意识叠加多个变量，但必须：

- 明确模拟目标；
- 降低附近其他高成本刺激；
- 预留恢复窗口；
- 使用 24–48 小时吸收结果决定是否继续推进。

## 八、降级与退出

出现以下情况时缩短时长、降低 D−/技术难度、改为可跑路线或取消：

- 周前已累积高机械负荷；
- 局部疼痛达到黄灯边界或动作代偿；
- 睡眠、HRV 趋势、晨起心率和主观恢复共同恶化；
- 路线相对新颖度过高且缺少可退出点；
- 补给、热湿或装备条件超出当前可控范围；
- 会破坏下一堂更高优先级训练。

出现走路疼、疼痛改变跑姿、神经症状、胸部症状、意识异常或热病信号时停止并寻求专业帮助。

## 九、输出

设计或复盘山地长课时，输出：

1. 当前能力块与训练目的；
2. 外部负荷目标；
3. 内部反应 guardrails；
4. 机械/神经肌肉成本；
5. 相对新颖度；
6. 本次唯一主推进变量；
7. 补给、装备和环境策略；
8. 黄灯降级与红灯退出；
9. 24–48 小时吸收指标；
10. 下一次是否进阶的判定。
