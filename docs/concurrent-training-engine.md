# Concurrent Training Engine

## 一、目标

在耐力、力量、ME、下坡和恢复之间分配有限的训练质量与恢复预算。同期训练的判断框架是：

> 竞争 + 干扰 + 协同

不得默认“有氧会把力量练没”，也不得因为每堂课单独有用就把它们全部叠加。

## 二、四层干扰模型

### 急性疲劳竞争

前一堂课可能降低后一堂课的重量、速度、动作质量或输出。先检查糖原、局部肌肉、神经肌肉状态和主观 RPE。

### 恢复资源竞争

跑量、D+、D−、技术地形、力量、睡眠、营养、生活压力和可用时间共同消耗恢复预算。

### 适应信号竞争

AMPK/PGC-1α 与 Akt/mTORC1 等通路只能解释部分机制。不得用单一分子通路预测长期训练结果。

### 训练信号稀释

同一能力块同时主攻过多能力，会使每项刺激都不够集中。每块只保留 1–2 项主适应，其余能力维护或暂时弱化。

## 三、训练优先级

> 当前能力块的主适应优先获得新鲜状态。

- 最大力量块：保护重力量质量；
- VO₂max / 阈值块：保护跑步关键课；
- 长距离专项块：保护山地时长、D+、D−、补给和疲劳态技术；
- 爆发或弹性刺激：只在足踝绿灯和神经肌肉新鲜时安排。

同日必须完成两类训练时，先做当前主适应。能分开数小时通常更稳妥，但不得把固定小时数写成所有人的硬规则。

## 四、机械与神经肌肉负荷账本

以下项目即使心率不高，也可能与力量训练竞争：

- 长技术下坡；
- 高量真实 D−；
- 台阶下降；
- ME；
- 超长山课；
- 重力量；
- 疲劳态连续下降；
- 高量极简鞋或五指鞋坡度跑。

每日和每周同时记录：

> 代谢负荷 + 机械负荷 + 神经肌肉负荷

优先判断过去 48–72 小时是否重复使用同一局部组织。

## 五、力量日与低强度跑

力量日不自动等于无跑日。力量与低强度跑同日时：

- 先确认当前能力块的主目标；
- 若最大力量是主适应，通常先力量、后低强度跑；
- 跑步只承担低成本有氧容量或活动，不做 progression、阈值、ME 或额外高离心；
- 使用完整说话、RPE 2–3、明显低于 AeT、动作自然作为 guardrail；
- 若力量后动作失控、局部症状增加，或会破坏 48 小时内更重要的训练，缩短或取消跑步。

若跑步关键课是主适应，则优先保护跑步质量，力量改为支持、维护或顺延。

## 六、低强度有氧、恢复跑与完全休息

### 低强度有氧

用于建设或维持有氧容量与跑步暴露。虽然单位恢复成本低，但仍然是训练负荷。

### 恢复跑

以极低成本活动为首要目标，训练收益是附带收益。成功标准：

> 跑完至少不比跑前更累，理想状态是更松、更顺。

### 完全休息

当睡眠严重不足、全身疲劳明显、局部机械风险升高、热身后仍不顺，或恢复跑本身会成为额外负担时，完全休息优先。

## 七、证据边界

- 同期训练通常可以同时提升耐力和力量；爆发力和快速力量更容易受同 session 干扰；
- 最大力量提高的是力量储备，不保证上坡经济性同步改善；
- RDL、分腿蹲、step-down 和提踵可建立机械储备，但不能替代真实下坡专项暴露；
- Build reserve → Transfer → Specific exposure → Retain 是训练组织原则，不是唯一被证明的序列；
- ME 间隔、能力块长度和赛前最后一堂 ME 的时间都是个体化起点，不是普适生理定律。

## 八、决策问题

每次组合或删除训练前回答：

1. 当前最值得保护的适应是什么；
2. 过去 48–72 小时是否已有使用同一局部组织的高机械刺激；
3. 这堂课是否降低下一堂更高优先级训练的质量；
4. 当前需要增加低成本容量，还是保留恢复预算；
5. 适应收益 / 恢复成本是否高于更低成本替代方案或休息；
6. 哪些结论是证据共识，哪些只是条件性工具或实践假设。

## 九、输出

输出至少包含：主适应、竞争负荷、训练排序、主方案、低成本替代方案、取消标准和训练后观察指标。
