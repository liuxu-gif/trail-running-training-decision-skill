# 个性化测试与校准

## 先决定测试是否值得

目标是让能力基准、训练刺激、适应证据与下一能力块连接起来。每位使用者均先检查：训练资历、健康与疼痛、最近负荷、赛历、可用器材、既有原始记录、测试经验和要解决的训练问题。

| 情形 | 决定与训练后果 |
| --- | --- |
| 已有近期、同条件、可追溯数据 | 复用；说明可信度与局限，不重复测 |
| 新手、久停后重建或动作基础未知 | 低疲劳筛查、熟悉动作与 easy 观察；先给保守训练 |
| 强度锚点不明且会改变处方 | 条件允许时选一项针对性测试；结果前用对话、RPE 与动作控制 |
| 疼痛、疾病、明显疲劳、赛前减量或高 D− 尚未吸收 | 延后表现测试；恢复、观察或按需专业评估 |
| 多个指标冲突或环境不可比 | 先查设备、天气与近期疲劳，保留不确定性，不用一次结果改方向 |

每次输出一张测试卡：目的、为什么现有数据不足、适用人群、恢复门、流程、待替代的训练、原始记录、停止标准、解释规则和结果如何调整下一计划。用户实际完成并提供记录后才能写成已完成测试。

## 低疲劳动作筛查与进阶

可把筛查嵌入结构支持课，替换其部分内容。选择无痛、可控的动作，不要求所有人一次完成全套：

- Air Squat：徒手深蹲约 5 次，观察足弓、膝轨迹、躯干和疼痛。
- Box Step：低台阶上步每侧约 5 次，观察骨盆、共轴与推蹬。
- Sit-to-Stand：高座椅单腿坐站每侧约 3 次，允许扶助；困难时退为双腿或更高座椅。

记录椅/台阶高度、扶助、ROM、两侧控制、疼痛及次晨反应。次数是起始示例，没有统一及格线；不能凭一次偏移诊断肌群无力或损伤。

Stage 1：无痛基础动作与双侧控制；Stage 2：稳定且次晨无不良反应后，提高台阶、控制难度或轻负重之一；Stage 3：逐步转向有记录的负重 Step-up 与专项动作。负重下降、疲劳态动作和短坡冲仍需各自机械恢复门。Stage 是本项目训练标签，不是医疗分期或强制升级日历。

## AeT 现场校准

仅在跑者已能轻松承受测试所需时长、恢复稳定且环境可控时使用。否则先积累较短 easy 数据，不强迫完成一小时。

1. 使用可靠心率记录，优先胸带；固定熟悉跑步机、速度、坡度、鞋和散热条件。
2. 渐进热身约 15–20 分钟，待呼吸与心率稳定，再开始独立记录。
3. 做约 60 分钟恒定外部输出，测试中不追心率调速；记录前后各 30 分钟均值 H1、H2。
4. 恒定速度/坡度时，漂移 = (H2 − H1) / H1 × 100%。变速、暂停、扶扶手、传感器异常或环境明显变化时，标为不可直接比较。户外变速/起伏数据不能直接套此公式估 AeT。
5. 结合 RPE、呼吸、温湿度、补给和局部反应解释。约 5% 为教练现场参考；低漂移仅说明该输出下较稳定，高漂移也可能受热、疲劳或脱水影响。一次结果不产生精确 LT1；有必要才择日小幅调整输出验证。

出现疼痛、明显动作失控、头晕、胸部症状或异常呼吸即停止；未完成也保留记录，不补测凑时长。数据不可靠时保持原有保守范围。

## AnT、CS 与表现基准

- AnT/LT2：先复用可靠近期测试或合适比赛。若确需新测试，为具备基础、无禁忌且恢复良好的跑者选择明确的持续计时方案，写清方法、配速策略、记录与解释边界；新手或风险不明者不直接安排最大计时。实验室气体/乳酸检测是可选校准方式。
- CS：需要不同持续时间的有效计时数据及明确拟合方法，试次间充分恢复；只有单个 3–5K 成绩时不能据此报告实测 CS/W′。缺少协议或模型时仅把成绩当表现基准。
- 固定 800m 等课程：相同组数、工作强度、恢复、场地与天气下比较衰减和 RPE；换恢复比后不能当同一次测试。课程成绩、手表估计值均不等于实验室 VO₂max。
- Ten Percent Test：只有 AeT 与 AnT 心率均有可靠且可比估计时，才用 (AnT HR − AeT HR) / AnT HR 作实践性参考。约 10% 差距是 Scott 方法的启发式，不是 ADS 临床诊断或自动增加强度的开关。

## 审计、频率与结果回流

每周复用 easy、质量课 Lap、比赛、力量和主观恢复记录。较大阶段或赛事转换时审计能力，通常约 6–10 周只是参考；表现测试按问题触发，每年约 1–3 个高质量机会仅是规划思路，不是上限、最低数或人人配额。

若连续两个块缺少某能力刺激，先检查真实完成记录和比赛需求；只有趋势明确、该能力即将重要且自然数据不足，才选一项额外基准。力量与动作复评优先用训练中的同 RPE 重量、ROM 和质量，不追 1RM。

结果回流：动作不稳→退阶并控制负重；可信漂移/呼吸变化→保守调整 easy 工作范围；同条件持续表现改善且恢复稳定→考虑下一项小进阶；条件不一致或结果冲突→暂不改阈值。记录每个判断的依据及下次验证触发条件。

环境记录至少包含实际气温、湿度、风、日晒，露点/热指数或 WBGT 可得时补充。不同天气可分层或定性比较，不套未经个人标定的每升温 1°C 自动加减秒数。
