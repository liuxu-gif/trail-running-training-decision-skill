# 周类型、质量课与能力审计

## 周类型

B/I/R/S/T/G 是本项目借鉴 Scott 周期思路的操作标签，不是原书逐字周名，也不替代弹性周期。

| 类型 | 主任务 |
| --- | --- |
| B 基础/巩固 | 有氧容量、一般/最大力量储备、动作质量 |
| I 强度建设 | 集中发展一项需要的主强度，其他高成本课让位 |
| R 恢复 | 吸收赛事或机械负荷、低强度重建 |
| S 专项 | 地形、D+/D−、补给、长时间移动与疲劳后可跑 |
| T 减量 | 保留熟悉跑感和必要触点，降低量与机械疲劳 |
| G 赛事 | 围绕目标赛执行，保护恢复和补给 |

每周标一个主类型，其他能力条件性维护；不生成固定每周强度配额。检查总量/连续跑、D+/D−、主强度、力量与结构支持、下一关键课与恢复资源五个维度。

## 实际能力块审计

回看约 4–6 周真实完成的力量次数、负重与 RPE 进阶、质量课工作量、专门 ME、比赛替代课、取消课与无法训练天数。连续有效刺激—恢复—再刺激才支持“发展块”；间断触点标为维护或重建。计划标题不等于实际适应。

为目标能力设基准与复评触发条件，按实际训练证据判断维持、进阶、退阶或更换块。不得因某项能力数月未训练，就默认一直维持；也不因发现空缺自动补最大测试或额外间歇。测试决策见 `testing-and-calibration.md`。

## 完整质量课处方

先明确发展的是有氧功率、CS/阈下、动作速度还是专项上坡，再规定强度依据、单段时长/距离、组数、组间恢复方式/时长、累计工作量、场地、机械成本、进阶与取消标准。

- 400/800/1000m 是距离工具；实际配速、持续时间与恢复比决定刺激，不能按距离命名生理效果。
- 定时 2–4 分钟、30/30、连续阈下和长坡段均可择用；30/30 的快速段保持受控，不是全力冲刺。
- CS 与 LT2 的处方锚点分别说明；设备默认 Z3/Z4 与 Scott 分区须先校准含义。
- 按近期实测能力与耐受从可完成的低剂量开始，优先改一个变量。记录逐组表现、衰减、RPE、次日和下一主课；累计工作分钟不能当实测 T@VO₂max。
- 坡上质量、专门 ME、重力量、高 D− 和赛事共同竞争恢复；以替代、缩量、顺延为工具，不把各课型研究模板拼成一周。

## 短坡冲

服务神经肌肉招募和坡上协调；不能替代有氧主质量或专门 ME。充分热身后，在稳定安全的熟悉坡面做数次约 8–10 秒受控快速动作，组间完整走回恢复；具体次数、坡度与努力按经验和局部耐受选择，不追力竭。

足踝/跟腱疼痛、步态异常、高 D− 后未吸收或邻近关键课恢复不足时取消。引入时减少或替换同日下肢力量主组；总工作时长短仍有峰值机械负荷。不把作者个人试行剂量固化为所有人的处方。

## 减量与炎热赛事复盘

减量优先降低恢复成本最大的变量，包括高 D−、技术下降、重腿力量、大规模 ME 和超长课；根据此前负荷、赛事定位及恢复保留熟悉 easy、频率和少量必要触点。不能按一个比例同时削减所有维度，也不能因心率低就视长跑为零机械成本。

热湿下高心率不能单独证明抢跑，后程心率降低也不能单独证明有氧耗尽。结合主动配速、外部输出、地形、RPE、气象、补给、局部症状和动作判断。痉挛原因保留多因素解释，不直接诊断缺钠、脱水或力量不足；不推算“若无抽筋”的精确成绩。
