# Personalization Engine

## 一、目标

将通用训练理论转化为个体化决策。AI 不应从“赛事距离”直接跳到“课表”，而应依次处理：

1. 跑者是谁；
2. 当前在哪里；
3. 目标是什么；
4. 有什么限制；
5. 身体现在是否允许；
6. 哪些刺激最值得；
7. 哪些刺激机会成本过高。

## 二、输入

### Runner Profile

读取：

- 年龄、性别；
- 跑龄和越野经验；
- 过去 4–8 周跑量、D+、D−、山地时长和技术地形暴露；
- 最长山地活动；
- 力量经验；
- 可训练时间；
- 场地器械；
- 恢复基线；
- 伤病史；
- 技术短板；
- 偏好和生活限制。

### Race Profile

读取：

- 日期；
- 距离；
- 爬升；
- 垂直密度；
- 海拔；
- 技术难度；
- 长下坡；
- 最长连续爬升与下降；
- 台阶；
- 气候；
- 夜跑；
- 预计时长；
- 补给站；
- 登山杖规则。

### Assessment Screen

读取：

- 疼痛与健康红旗；
- 单腿控制；
- 髋稳定；
- 足踝能力；
- 核心和背部；
- 力量动作熟练度；
- 下坡经验；
- 补给和热适应。

## 三、多维等级

L0–L3 只是初筛。还要分别判断：

- 代谢等级；
- 力量等级；
- 机械等级；
- 技术等级；
- 补给等级；
- 恢复等级。

可能出现“代谢 L3、机械 L1”。此时不能按整体 L3 安排高离心或高阶 ME。

## 四、阶段判断

- 赛后恢复；
- 一般准备；
- 有氧容量；
- 最大力量；
- VO₂max/有氧功率；
- CS/阈下；
- ME 转化；
- 长距离专项；
- 比赛实现；
- taper。

## 五、短板判断

### 代谢门短板

- easy 心率高；
- 漂移明显；
- 爬坡心肺先爆；
- 长距离输出快速下降。

### 力量短板

- 单腿力量弱；
- 小腿与比目鱼肌承载差；
- 负重动作长期无进步；
- 上坡局部肌肉过早失效。

### 机械门短板

- 下坡股四快速失效；
- 足底、跟腱、小腿反复反应；
- 疲劳后动作崩；
- 出现代偿或疼痛。

### 执行门短板

- 前半程过快；
- 不愿走；
- 补给拖延；
- 胃不适后处理失控；
- 夜间或热湿环境决策差。

## 六、能力块选择

每次只选 1–2 个主目标，例如：

- 最大力量 + 有氧维护；
- VO₂max + 技术下坡维护；
- ME + 补给；
- 长距离专项 + 力量维护；
- 恢复 + 动作重建。

不得把所有短板同时列为主目标。

当前主目标必须获得最高质量刺激。其余训练按“维护、条件保留、顺延或取消”处理，并说明适应收益与恢复成本。

## 七、周结构生成

先确定：

- 本周最高优先级训练；
- 第二优先级训练；
- 可承受的高负荷刺激数；
- 可训练日；
- 恢复日；
- 场地限制。

然后再排星期。星期不是起点。

同时建立三本负荷账：代谢、机械、神经肌肉。下坡、台阶、ME、高 D−、重力量和超长山课不得仅按心率归类为低负荷。

## 八、赛事需求反推垂直容量

高垂直密度赛事可从赛事 D+、D−、山地时长和技术要求反推专项建设，但不把比赛爬升复制成每周硬门槛。

- 赛事爬升的 80%–120% 只能作为有训练基础跑者专项建设周的经验性软参考；
- 同时监控 D−、最长连续爬升与下降、技术地形、疲劳后可跑性和补给；
- 使用能力块和波浪式增加，并安排吸收周；
- 周中坡度有氧提供低离心垂直容量，ME 提供上坡张力，真实山地承担技术、下降、装备与补给；
- 新增爬升若持续破坏强度、力量、睡眠或局部组织稳定，说明超过可吸收能力；
- 相似赛事可跨赛季保留垂直底座，不在赛前短期突击。

## 九、力量个性化

- 动作基础不足：一般力量与技术；
- 有基础、远离比赛：Build reserve；
- 有力量基础、进入专项：Transfer + 最大力量维护；
- 技术和下坡需求升高：Specific exposure；
- 临近比赛：最低有效剂量，不追进步、不产生 DOMS。

## 十、输出

必须区分：

- 通用原则；
- 基于 Profile 的判断；
- 明确假设；
- 当前主适应、竞争负荷和恢复预算；
- 证据共识、条件性工具和个体化实践参数；
- 尚需验证的信息。

不得把估计写成已测数据。
