# Example Week Plan

> 虚构示例，仅展示输出结构。

## 当前阶段

一般准备期，主目标为最大力量和低强度容量。

## 本周优先级

1. 最大力量主课；
2. 周末 3 小时山地；
3. 其他能力维护。

## 周结构

- 周一：最大力量主课 + 短 easy
- 周二：easy
- 周三：3×8min 阈下
- 周四：结构支持力量
- 周五：休息
- 周六：3 小时山地低强度
- 周日：恢复跑或徒步

## 黄灯

- 周一主力量改 2×3 神经触点；
- 周三改 easy + strides；
- 周六缩短至 2 小时。

## 红灯

取消力量、强度和山地长课，不补课。
