# Example Week Plan

> 虚构示例，仅展示输出结构。

## 当前阶段

一般准备期，主目标为最大力量和低强度容量。

## 本周优先级

1. 最大力量主课；
2. 周末 3 小时山地；
3. 其他能力维护。

## 适应与负荷账本

- 主适应：最大力量储备；
- 代谢负荷：低到中；
- 机械 / 神经肌肉负荷：周一重力量、周六山地；
- 竞争控制：周一短 easy 只保留低成本容量，不做 progression；周三质量课前不叠加高机械刺激。

## 周结构

- 周一：最大力量主课；数小时后可选短 easy（RPE 2–3、完整说话、动作自然）
- 周二：easy
- 周三：3×8min 阈下
- 周四：结构支持力量
- 周五：休息
- 周六：3 小时山地低强度
- 周日：恢复跑或徒步

## 黄灯

- 周一主力量改 2×3 神经触点；
- 若力量后动作变差或局部症状增加，取消短 easy；
- 周三改 easy + strides；
- 周六缩短至 2 小时。

## 红灯

取消力量、强度和山地长课，不补课。

## 训练后观察

- 周一力量质量与短 easy 是否互相干扰；
- 24/48 小时 DOMS；
- 周三阈下质量；
- 周六真实下坡后的股四、足踝和动作衰减。
